## Contoh template repo ini

Seluruh contoh template di `src/data/templates.ts` beserta turunannya
(`templates/manifest/manifest.json`, `templates/examples/synthetic/`)
adalah **data sintetis yang dibuat lokal oleh tim NitZ-909 untuk pengujian**
(kepanitiaan, rekap berkas, rapat koordinasi — bukan kejadian nyata).
Setiap template diakhiri penanda DATA UJI.
